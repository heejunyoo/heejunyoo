# Heejun Yoo

I build practical AI products with an emphasis on evidence, traceability, and real user workflows.

## Featured projects

- **[Paper / Recall](https://github.com/heejunyoo/paper-learning-public)** — Evidence-grounded learning from user-selected material, with retrieval practice, source-linked explanations, and explicit verification boundaries.
- **[Ingreed](https://github.com/heejunyoo/ingreed-public)** — Korean processed-food ingredient grading based on regulatory evidence, with a shared TypeScript scoring engine and a [live demo](https://ingreed.vercel.app).
- **[ai-pms](https://github.com/heejunyoo/ai-pms)** — Multi-user agent project monitoring: goals, artifacts, verification, and MCP data-source provenance. Demo screens use synthetic data.

## Working principles

- Separate local tests and mocked behavior from live production evidence.
- Make sources, limitations, and data handling visible to users.
- Optimize the path from first visit to the product's core action.
